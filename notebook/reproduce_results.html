Reproducing the numerical study¶

On the (non-)coincidence of the serial and Shapley solutions in multi-server queueing and scheduling problems (Banerjee and Trudeau), Section 6.

This notebook already shows its results. Nothing needs to be run to read it. To re-run it, choose Run > Run All Cells; with the settings below that takes about two minutes. The folder launchers/ opens this notebook on Windows, macOS and Linux with nothing else installed, and the README has a link that opens it in Google Colab.

Part What it does
1 Sets up, and shows the versions in use
2 Works through the paper's running example
3 Checks the fast Shapley calculation against the definition
4 Recomputes a sample of problems and compares them with the saved study
5 Rebuilds the numbers of Section 6, Table 3 and Figure 1, and compares them with the paper
6 Shows the distance from the bound of Proposition 2
7 Runs the automated tests
8 Optional: re-runs all 78,480 problems

2. The running example¶

Three groups share $k=2$ servers, with job lengths $l=(2,3,6)$ and $w_0=1$. With divisible jobs, the shortest jobs go first, and a group's waiting cost runs until its last unit is done.

The two rules differ for groups 2 and 3, as in Table 2 of the paper. The gap comes from rounding: a job that ends part-way through a period leaves a slot that the next job uses.

3. The fast calculation against the definition¶

shapley_opt_div is the dynamic program of Section 6, in $O(n^3k)$ operations. brute_shapley applies the definition over all $2^n$ coalitions, which is only possible for small $n$.

In [4]:
import random
rng = random.Random(0)
worst = 0.0
for _ in range(200):
    n = rng.randint(1, 10)
    k_ = rng.choice([1, 2, 3, 4, 5, 8, 16])
    l_ = [rng.randint(1, 3 * k_ + 2) for _ in range(n)]
    worst = max(worst, float(np.max(np.abs(shapley_opt_div(l_, k_) - brute_shapley(l_, k_)))))
print(f"Largest difference over 200 random problems: {worst:.1e}")

Largest difference over 200 random problems: 5.0e-14

def flat(d, prefix=""):
    out = {}
    for key, value in d.items():
        if isinstance(value, dict):
            out.update(flat(value, f"{prefix}{key} / "))
        else:
            out[prefix + key] = value
    return out

6. Distance from the bound of Proposition 2¶

The bound is $|Sh_i-Ser_i|\le w_0\,n(k-1)/k$. The largest gap found, as a share of the bound, stays at or below one half, in the grid and in the hill-climbing searches.

8. Optional: all 78,480 problems¶

Set RUN_FULL_GRID = True at the top. The new file is compared with the saved one, value by value and byte by byte. Bytes can differ across machines through floating-point noise in the last digits; the designs, the flags and the values reported in the paper do not.

This part takes about 20 minutes on a laptop and over half an hour on Google Colab, and it prints nothing until it ends. On Colab, keep the tab open; it is best run on your own computer.
