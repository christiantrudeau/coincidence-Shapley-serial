# Data

`grid_results.csv` holds one row for each of the 78,480 simulated problems of the study (16 MB). The
data is generated by this repository's code and comes from no external source.

- How it is generated, with a worked example and the meaning of each column:
  [`docs/how_the_data_is_generated.md`](../docs/how_the_data_is_generated.md).
- How to regenerate it: `python src/reproduce_all.py`, which writes to `outputs/` and compares the
  new file with this one.

`robustness_b.csv.gz` holds the 213,840 problems of the robustness check (8 MB compressed; pandas reads it
directly). How it is generated and what it shows: [`docs/robustness_b.md`](../docs/robustness_b.md).
